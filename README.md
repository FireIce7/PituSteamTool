# PituSteamTool

Switch Steam between 32-bit and 64-bit. | Alterne a Steam entre 32-bit e 64-bit.

## Quick Start | Início Rápido

Paste in PowerShell: | Cole no PowerShell:

```powershell
iwr -useb "https://raw.githubusercontent.com/FireIce7/PituSteamTool/main/PituSteamTool.ps1" | iex
```

Requests admin automatically. | Pede admin automaticamente.

## Options | Opções

| # | EN | PT-BR |
|---|-----|-------|
| 1 | **Downgrade** — Replace Steam with 32-bit binaries | **Downgrade** — Substitui a Steam por binários 32-bit |
| 2 | **Upgrade** — Remove downgrade lock, Steam updates to 64-bit | **Upgrade** — Remove trava, Steam atualiza para 64-bit |
| 3 | **Deep Repair** — Deletes client files, Steam rebuilds from scratch | **Reparo Profundo** — Apaga arquivos do cliente, Steam reconstrói |

Your games, saves, configs, and logged accounts are **never** deleted.

Seus jogos, saves, configs e contas logadas **nunca** são apagados.

## Requirements | Requisitos

- Windows 10/11
- PowerShell 5.1+
